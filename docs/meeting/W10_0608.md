## Executive Summary
This meeting focused on defining a **Two-Stage Workflow** for processing cattle tracking data and specifying the core rules for an **Automated Anomaly Detection Pipeline**. The project scope clarifies that while fully automatic Re-ID falls under PhD-level research, an automated error-scanning pipeline paired with an interactive correction tool provides a robust and high-value MSc dissertation contribution.

---

## 1. Two-Stage Workflow Architecture

* **Stage 1 (Frame-Level Cleaning):** Refine bounding boxes and resolve ID swaps on keyframes using `app_frame.py` to export clean, standardized JSON annotation files.
* **Stage 2 (Macro View & Error Detection):** Load cleaned JSONs into a high-level review system (`app_video.py`) to inspect long-term trajectories, cross-camera transitions, and macro-level dataset consistency.

---

## 2. Automated Anomaly Detection Pipeline Rules

To efficiently process large volumes of dataset tracking without manual inspection of every frame, an automated detection module will scan tracklets and flag potential errors based on four core physical constraints:

| Rule | Description & Logic | Flagged Error Type |
| :--- | :--- | :--- |
| **1. Spatial ID Consistency** | For any position in 2 adjacent frames, the ID should remain the same. High bounding box overlap (IoU) with differing IDs indicates an ID swap. | `ID_SWAP` / `ID_FLIP` |
| **2. Velocity / Jump Threshold** | Total distance a cow moves per second must remain below a maximum threshold ($v < \text{MAX}$). Unrealistic displacement indicates tracking jumps. | `UNREALISTIC_JUMP` |
| **3. Boundary & Transition Continuity** | When a cow leaves one camera frame near an overlap area, it should eventually arrive in an adjacent camera within a reasonable time window. | `TRANSITION_LOST` |
| **4. Bounding Box Stability** | Bounding box size, aspect ratio, and rotation angle ($\theta$) should not change dramatically over a short time interval. | `GEOMETRIC_DEFORMATION` |

## 3. Academic Value & Dissertation Scope

* **Scope Boundary:** Fully automated multi-camera Re-ID is PhD-level research; however, developing a rule-based anomaly detection pipeline paired with an interactive refinement UI represents an ideal scope for an MSc dissertation.
* **Core Value Proposition:** The software not only identifies where the dataset tracking fails but also provides a streamlined, interactive tool to inspect and correct those errors efficiently.
